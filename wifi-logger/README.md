# Wi-Fi切断ロガー

トレーニング室のBGM用Androidタブレットで、Wi-Fiが切れた時刻と復旧までの時間を自動で記録するツールです。
「なんとなくよく切れる」を、業者や管理会社に見せられる記録に変えることが目的です。

公開中のページ(Artifact): https://claude.ai/artifact/8NHQ27xYX4fWZ4hRvKZekD
(claude.ai上では private 設定です。共有するにはページの共有メニューから設定してください)

## 使い方

1. タブレットのChromeで上のURLを開きます。
2. 画面下の**「監視を開始」**を押します。以後30秒ごとに通信を確認し、切断を記録します。
3. 切断が起きると、表に**発生日・切断開始・復旧時刻・停止時間**が自動で追加されます。
   その場で**在室人数**を入力しておくと、CSVにそのまま出力されます。
4. 記録を渡すときは**「切断記録を保存」**を押してCSVを書き出します。
   応答時間まで含めた生データが必要なときは「全記録を保存」です。

## 使うときのコツ

- **Chromeを前面に出したままにしてください。** 他のアプリに切り替えるとAndroidが計測を止めます。
  止まっていた区間は、記録上「計測中断」として残るので、後から見分けがつきます。
- 茅ヶ崎FMアプリと併用したいときは、**画面を分割**して片側にChromeを置いてください。
- 終日動かす場合は**電源に接続**してください。「監視中は画面を消さない」が既定で有効です。
- 3分操作がないと画面が暗くなります(焼き付き・電力対策)。**切断が起きると自動で明るく戻ります。**

## 記録は消えません

記録は数秒ごとにタブレット内に保存されます。Chromeを閉じても、電池が切れても、
次に開いたときに**「前回の記録が残っています」**と表示され、`続きから再開` / `記録を書き出す` / `破棄`
を選べます。破棄を選ぶまで消えないので、慌ててCSVに書き出す必要はありません。

## 設定(「監視の設定」を開く)

| 項目 | 既定値 | 何を変えるか |
| --- | --- | --- |
| 監視先 | cdnjs と jsDelivr の小さなJSファイル(各約1.5KB) | 外部インターネットへの疎通を見ます。**claude.ai上で開いている場合は、この2つのCDNのJavaScript以外には届きません**(下記) |
| 確認の間隔 | 30秒 | 短くすると細かく取れますが、通信量と電池を使います |
| 応答待ち | 8秒 | この時間で応答がなければ失敗とみなします |
| 切断とみなす連続失敗 | 2回 | 1回の失敗は一時的なパケットロスのことがあるため、既定では2回続けて失敗したときに記録します |

監視先の変更は監視中はできません(記録とCSVの監視先がずれるため)。他の3つは監視中でも変更でき、次の確認から反映されます。

### 館内のゲートウェイやAPを監視したいとき

claude.aiのページには安全設定(CSP)があり、外部への通信は **cdnjs.cloudflare.com / cdn.jsdelivr.net からの
JavaScript読み込み**しか通りません。`fetch` や画像の読み込みはどこ宛てでも止められます。
このため、館内機器のURLを監視先に足しても claude.ai 上では「×」になります。

館内の区間まで切り分けたい場合は、`index.html` をタブレットに保存してChromeで直接開いてください
(ファイルを開くだけで動きます。CSV保存はブラウザのダウンロードになります)。この開き方なら
任意のURLを監視先にでき、`.js` 以外のURLは `fetch` → 画像読み込みの順に確かめます。

**「接続テストを実行」**で、監視先に届くか・どの方式で届くかを先に確かめられます。

## 技術メモ

- 単一HTMLファイルです。外部リソースを一切読み込みません(Wi-Fiが切れる前提の道具なので、
  Webフォントも使わず端末内蔵の書体だけで組んでいます)。
- CSV保存は Artifact の `downloads` capability を使い、素のブラウザで開かれたときだけ
  Blob + `<a download>` に落とします。**publish時に `downloads` を宣言しないとビューア内で保存が効きません。**
- 疎通確認は、URLが `.js` なら `<script>` 読み込み、それ以外は `fetch(mode:"no-cors")` → 画像読み込みの順に試し、
  一度届いた方式をURLごとに覚えます。claude.ai のビューアで通るのは `<script>` だけなので既定の監視先はJSです。
  ブラウザからは「どのAPに繋がっているか」までは分からないため、記録できるのは**疎通の有無**です。
